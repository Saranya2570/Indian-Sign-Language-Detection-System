🤟 Indian Sign Language Detection System

🌟 Overview

The Indian Sign Language Detection System is a Computer Vision and Deep Learning project that recognizes Indian Sign Language (ISL) hand gestures in real time. The application captures hand gestures through a webcam, processes the images using OpenCV, and predicts the corresponding sign using Machine Learning and Deep Learning models. The recognized gesture is then converted into text, making communication easier between hearing-impaired individuals and people unfamiliar with sign language.

✨ Features

- Real-time hand gesture recognition
- Webcam-based gesture detection
- Gesture-to-text conversion
- Implementation and evaluation of multiple Machine Learning models
- CNN-based real-time gesture prediction
- Simple and user-friendly interface

⚙️ Project Workflow

1. Capture hand gestures using a webcam.
2. Preprocess the captured images.
3. Extract hand features from the detected gesture.
4. Train and evaluate Machine Learning and CNN models.
5. Predict the corresponding hand gesture.
6. Display the recognized sign as text in real time.

🚀 How to Run

1. Clone this repository.
2. Install the required dependencies using:

```bash
pip install -r requirements.txt
```

3. Open the project in Visual Studio Code or your preferred Python IDE.
4. Run `main.py`.
5. Select the prediction module.
6. Show an Indian Sign Language hand gesture in front of the webcam.
7. The application recognizes the gesture and displays the predicted text.
